# DataMax-LSI 发布站

## 产品事实

DataMax-LSI 是部署在 Linux 存储服务器本机的 RAID 与数据管理台。它通过
Broadcom StorCLI、smartctl 和 Linux sysfs 读取控制器、虚拟磁盘、物理磁盘、
SAS 背板、NVMe、bcache 与主机状态，并提供告警、维护、备份、报表和多机管理。

## 发布站访客

- 正在评估存储管理工具的运维负责人；
- 准备下载安装包的存储管理员；
- 已部署产品、需要查操作步骤的一线值班人员。

## 发布站必须做到

1. 首屏说明产品是什么、解决什么问题、当前可下载版本是什么。
2. 用真实产品截图证明功能，不使用虚构客户、价格或性能数据。
3. 下载包、SHA-256、安装前置条件和详细手册均可直接找到。
4. 页面可静态托管，不依赖外部字体或 CDN。

## 不做什么

- 不把未实现的能力写成已发布功能；
- 不使用虚构的客户 Logo、评测引语或吞吐数据；
- 不把 Broadcom 专有 StorCLI 二进制打包进公开安装包。
